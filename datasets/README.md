# Dataset Files

The raw datasets are not included in this public portfolio repository.

To rerun the notebooks locally, place the required files in this folder with the following names:

```text
datasets/
├── PopulationProfit.csv
├── housing-dataset.csv
└── ex1data2.txt
```

Expected usage:

- `PopulationProfit.csv` is used for simple linear regression with one feature.
- `housing-dataset.csv` is used for multiple linear regression.
- `ex1data2.txt` is used for nonlinear kernel regression.

This folder intentionally contains only this README to avoid redistributing course-provided raw data files.
